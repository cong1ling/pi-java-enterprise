# CHANGELOG

## 0.1.0

Initial public release candidate for `pi-java-enterprise`.

### Added

- publishable Pi package structure with `skills`, `prompts`, `extensions`, `themes`, `docs`, and `examples`
- bilingual English and Chinese package documentation
- core Java skills for code review, refactoring, testing, and debugging
- enterprise Java skills for Spring Boot API development, MyBatis-Plus CRUD, Redis cache design, Kafka event handling, MySQL troubleshooting, and Spring Boot configuration troubleshooting
- prompt templates for API work, debugging, SQL analysis, module design, cache strategy, test planning, and Kafka consumer analysis
- lightweight helper extensions for Java project detection, Maven workflow hints, Maven test failure triage, Spring Boot startup diagnosis, and MySQL analysis guidance
- dark and light themes for enterprise Java work in Pi

### Notes

- version `0.1.0` is intended as a strong starting point, not a fully stabilized `1.0.0`
- workflows and extensions are intentionally lightweight and expected to evolve with real usage feedback
