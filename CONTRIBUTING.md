# Contributing to pi-java-enterprise

Thanks for contributing.

## Scope

This package is focused on enterprise Java backend development in Pi, especially:

- Spring Boot
- MyBatis-Plus
- MySQL
- Redis
- Kafka
- Maven
- JUnit 5

Please keep contributions aligned with that scope.

## Contribution priorities

Preferred contribution areas:

1. Higher-quality Java skills
2. Better prompt templates for backend workflows
3. Lightweight, reliable Pi extensions
4. Documentation improvements
5. Theme refinements for readability

## Guidelines

### Skills

- Keep skill names stable and lowercase
- Make workflows concrete and practical
- Prefer decision checklists over vague advice
- Avoid company-specific assumptions

### Prompts

- Keep prompts concise and reusable
- Focus on common Java backend tasks
- Prefer prompts that help Pi enter a clear workflow quickly

### Extensions

- Keep them lightweight and safe
- Avoid deep assumptions about private infrastructure
- Prefer diagnostics and hints over aggressive automation

### Docs

- Keep English docs clear and publishable
- Keep Chinese docs natural and useful
- Maintain terminology consistency between languages

## Review checklist for contributors

Before submitting changes, check:

- resource names still match filenames and directory names
- package paths in `package.json` remain correct
- skill frontmatter is valid
- prompt templates have useful descriptions
- themes keep valid Pi theme structure
- extension command output is readable and actionable

## Release expectations

For now, changes should aim to improve package quality for local installation and future npm publication.
