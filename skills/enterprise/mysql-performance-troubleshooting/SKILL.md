# MySQL Performance Troubleshooting

Use:

- actual SQL
- table schema
- indexes
- explain output
- row estimates and filter conditions

Avoid vague advice. Produce concrete optimization options, likely root causes, and trade-offs such as write amplification or storage growth from new indexes.
