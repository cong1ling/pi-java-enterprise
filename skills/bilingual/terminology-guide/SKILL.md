# Bilingual Terminology Guide

Use these preferred terms when writing or reviewing package content:

- idempotency / 幂等
- regression verification / 回归验证
- slice test / 切片测试
- aggregate root / 聚合根
- dead-letter queue / 死信队列
- transaction boundary / 事务边界
- cache invalidation / 缓存失效
- wiring / 装配

Prefer consistent terminology over literal but awkward translations.
