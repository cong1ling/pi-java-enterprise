# pi-java-enterprise Overview

`pi-java-enterprise` is a Pi package for enterprise Java backend development.

## Default stack

- Spring Boot
- MyBatis-Plus
- MySQL
- Redis
- Kafka
- Maven
- JUnit 5

## Primary goals

1. Improve daily API development workflows
2. Strengthen debugging and test-supplement workflows
3. Ship a reusable Java-focused package for Pi

## Resource types

- Skills for Java backend workflows
- Prompt templates for high-frequency tasks
- Lightweight extensions for project detection and hints
- Themes optimized for diagnostics and logs

## Recommended usage

- Use skills when you want Pi to follow a Java-specific workflow
- Use prompt templates when you want a fast task entry point
- Use extension commands when you need project-aware hints or diagnostics
- Use `java-enterprise-graphite` if you want the recommended JetBrains-like enterprise Java dark theme

## Best-fit scenarios

- Building or changing Spring Boot APIs
- Reviewing Java backend changes
- Planning JUnit 5 coverage
- Investigating Maven/Spring Boot failures
- Analyzing MyBatis-Plus query design and MySQL performance concerns
