# pi-java-enterprise 概览

`pi-java-enterprise` 是一套面向企业 Java 后端开发的 Pi package。

## 默认主栈

- Spring Boot
- MyBatis-Plus
- MySQL
- Redis
- Kafka
- Maven
- JUnit 5

## 核心目标

1. 优化日常接口开发
2. 强化问题排查与补测试工作流
3. 提供可发布、可安装、可复用的 Java 专项资源包

## 资源组成

- Skills：提供 Java 企业开发工作流
- Prompts：提供高频任务快捷入口
- Extensions：提供轻量项目识别与提示能力
- Themes：提供适合日志与诊断阅读的界面主题

## 推荐使用方式

- 需要 Pi 进入 Java 专项工作流时，优先使用 skills
- 需要快速发起常见任务时，优先使用 prompts
- 需要项目识别、命令建议、报错分类时，使用扩展命令
- 如果你偏好更符合 IntelliJ / JetBrains 气质的深色主题，推荐使用 `java-enterprise-graphite`

## 最适合的场景

- 开发或修改 Spring Boot 接口
- 审查 Java 后端代码改动
- 规划 JUnit 5 测试覆盖
- 排查 Maven / Spring Boot 启动失败
- 分析 MyBatis-Plus 查询设计与 MySQL 性能问题
